## 📥 Cara Instalasi & Penggunaan

Siapkan API Gemini terlebih dahulu

### 🪟 Pengguna Windows:
1. Clone atau download repository ini:
   ```cmd
   git clone https://github.com/Sinccbb/whatsapp-bot.git
   cd whatsapp-bot
   ```
   *(Atau klik tombol **Code > Download ZIP** di GitHub, lalu ekstrak foldernya).*
2. Masuk ke folder `Windows`.
3. Klik 2 kali pada file `install.bat`. Script akan otomatis memeriksa dan menginstall Node.js jika belum ada, memasang seluruh library, dan meminta API Key Gemini kamu.
4. Setelah selesai, klik 2 kali pada file `run.bat` untuk menyalakan bot!

---

### 🐧 Pengguna Linux / macOS:
1. Clone repository ini di terminal:
   ```bash
   git clone https://github.com/Sinccbb/whatsapp-bot.git
   cd whatsapp-bot
   ```
2. Berikan izin eksekusi script:
   ```bash
   chmod +x Linux/install.sh Linux/run.sh
   ```
3. Jalankan script instalasi otomatis:
   ```bash
   ./Linux/install.sh
   ```
   *(Script akan otomatis mengunduh Node.js, NPM, library bot, dan meminta API Key kamu).*
4. Jalankan bot kapan saja dengan:
   ```bash
   ./Linux/run.sh
   ```

nb : Kadang ada error di API key yang berasal dari penamaan ai model
